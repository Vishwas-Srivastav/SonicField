# Pull Request Standard Rule

All Pull Requests created for this repository MUST follow the standard template defined in [`.github/PULL_REQUEST_TEMPLATE.md`](file:///Users/vishwassrivastav/Desktop/Work/SonicField/.github/PULL_REQUEST_TEMPLATE.md).

## Required PR Format:

```markdown
## Summary
<!-- Concise explanation of WHAT was changed in this PR -->

## Why
<!-- Explanation of WHY this change is required and the context/problem it addresses -->

## Testing
<!-- Description of HOW changes were verified (unit tests, manual verification, build output) -->

## Related Work
<!-- Reference relevant issues or tasks, e.g., Refs SF-01 -->

---

## Checklist
- [x] Branch follows the naming convention (`<PROJECT_INITIALS>-<NUMBER>`, e.g., `SF-01`, `SF-02`)
- [x] Code adheres to project quality and naming standards
- [x] Tests pass locally and in CI
- [x] Build passes without warnings or errors
- [x] No secrets, tokens, or credentials were committed
- [x] Documentation has been updated (if applicable)
- [x] UI changes follow project UI standards (SVG icons, clean layout, no emoji as icons) (if applicable)
```
